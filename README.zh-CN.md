# UVMS 研究思路与伪代码

中文 | [English](README.md)

本目录为水下航行器–机械臂系统（UVMS）的说明资料，仅介绍研究动机、总体对照思路和非核心流程伪代码。

## 公开范围

本目录仅包含文字说明与纯注释伪代码，不提供实验或仿真观测、统计汇总、性能结果图、原始轨迹、示例数据集、训练产物、精确输入或参数配置。私有仿真器和控制实现保留在本目录之外。

相关研究面向数值仿真；本目录不提供实验结果证据，也不声称已经完成硬件验证、能够保证撤离成功或证明某种方法优于其他方法。

## 研究思路

水下接触作业中，末端载荷、航行器运动、机械臂反作用与执行器约束相互耦合。研究拟在一致的评价框架下，考察局部更新的接触治理和协调撤离的作用。这里仅描述问题与总体设计逻辑，不提供控制方程、增益、调参规则、平台标定或具体实现。

| 概念策略 | 对照作用 |
| --- | --- |
| Static | 固定接触治理，采用原始撤离策略 |
| Recovery | 固定接触治理，采用改进的撤离协调 |
| Proposed | 局部更新的接触治理，采用改进的撤离协调 |

Recovery 与 Static 的比较用于考察撤离协调；Proposed 与 Recovery 的比较用于在撤离协调一致的条件下考察接触治理。这些是对照定义，不是实验结果陈述。
